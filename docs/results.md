- **They show:** on synthetic fixtures, the code enforces the contract rules that were tested. Specifically:
  - `records100` is never counted.
  - Registry values are never overwritten.
  - Patients are joined on `exam_id`, not row position.
  - Labels never default to non-MI.
  - `confirmed` comes only from a review.
  - No patient group crosses splits.
  - Only confirmed rows reach training.

  - real ECG data, which was never downloaded or opened
